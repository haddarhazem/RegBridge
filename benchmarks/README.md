# Benchmarks

A benchmark is a fixed, versioned evaluation workload. Benchmark data must
have provenance, a described annotation process, an explicit version, and a
license that permits its use. Private data must never be committed, and a
benchmark change requires a version increment.

Do not add large datasets yet. A future benchmark should record its source,
license, acquisition method, creation date, version, transformations,
annotation methodology, and privacy restrictions. Manifests are tracked;
large or private data is not.

The example manifest in `manifests/` documents the convention without claiming
that the benchmark or its results exist.
