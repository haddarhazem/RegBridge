# EX-023 — Investor Opportunity Brief factuality verification

RQ-023 compares deterministic structured verification with semantic and hybrid
alternatives. The frozen synthetic benchmark contains 24 cases covering exact
facts, matching outcomes, UNKNOWN/MISMATCH protection, numeric claims,
paraphrases, invented customers/traction/partnerships/IP/team/compliance data,
prompt injection, and financial/success predictions.

Labels were frozen before candidate execution. No production data or private
brief content was used. V0 runs over the persisted claim/evidence shape and
the canonical SCRUM-203 dimensions. It never receives current mutable project
data.

V1 and V2 are optional research candidates only. They must return bounded
structured verdicts and may not create evidence or override deterministic
contradictions. A provider failure is BLOCKED, never a semantic result.
